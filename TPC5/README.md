## Resumo

* Neste 5º trabalho de casa, foi-nos solicitada a criação de uma aplicação em Python para analisar e alterar alunos e turmas através de diversas operações que devem surgir no monitor segundo o seguinte menu:
    - 1: Criar uma turma;
    - 2: Inserir um aluno na turma;
    - 3: Listar a turma;
    - 4: Consultar um aluno por id;
    - 8: Guardar a turma em ficheiro;
    - 9: Carregar uma turma dum ficheiro;
    - 0: Sair da aplicação

* Além disso, foi utilizado a seguinte estrutura para o modelo do aluno e da turma:

`aluno = (nome, id, [notaTPC, notaProj, notaTeste])`

`turma = [aluno]`

* No fim de ser executada a operação selecionada, deve ser apresentado novamente o menu, pedindo ao utlizadpr a opção para continuar ou sair.

* Por fim, foi-nos indicado que utilizassemos a aplicação para criar uma turma com 5 alunos, como exemplo.
