## Resumo

- Neste 4º trabalho de casa, foi-nos solicitada a criação de uma aplicação em Pythonque analisa e altera listas de inteiros através de diversas operações.
- O menu da aplicação deve ser o seguinte:
    * (1) Criar Lista 
    * (2) Ler Lista
    * (3) Soma
    * (4) Média
    * (5) Maior
    * (6) Menor
    * (7) estaOrdenada por ordem crescente
    * (8) estaOrdenada por ordem decrescente
    * (9) Procura um elemento
    * (0) Sair

- No desenvolvimento da aplicação deveriamos ter em atenção as seguintes indicações:
    * O utilizador irá escolher uma das opções introduzindo o número correspondente;
    * A aplicação tem que ter uma variável interna para guardar uma lista de números;
    * Na opção 1, deverá ser criada uma lista de números aleatórios entre 1 e 100 que será guardada na variável interna;
    * Na opção 2, deverá ser criada uma lista com números introduzidos pelo utilizador, que será guardada na variável interna;
    * Nestas primeiras opções, se a variável interna já tiver uma lista, esta seria sobreposta/apagada pela nova lista;
    * Na opção 3, será calculada a soma dos elementos na lista no momento;
    * Na opção 4, será calculada a média dos elementos na lista no momento;
    * Na opção 5, será calculado o maior elemento da lista no momento;
    * Na opção 6, será calculado o menor elemento da lista no momento;
    * Na opção 7, a aplicação deverá indicar (Sim/Não) se a lista está ordenada por ordem crescente;
    * Na opção 8, a aplicação deverá indicar (Sim/Não) se a lista está ordenada por ordem decrescente;
    * Na opção 9, a aplicação irá procurar um elemento na lista, se o encontrar deverá devolver a sua posição, devolverá -1 se o elemento não estiver na lista;
    * Se o utilizador selecionar a opção 0 (sair), a aplicação deverá terminar mostrando a lista que está nesse momento guardada e uma pequena mensagem
    * Se a opção não for sair, a aplicação executa a operação pretendida, apresenta o resultado e a seguir apresenta de novo o menu;
