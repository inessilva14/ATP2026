## Resumo

Neste 6º trabalho de casa, foi-nos solicitada a criação de uma aplicação em Python com um menu interativo para análise de uma tabela com dados metereológicos, na qual são guardados os registos de temperatura máxima e mínima e de precipitação ao longo de vários dias.
A variável que guarda estes registos é a tabMeteo, uma lista de vários tuplos, cada um correspondendo a um dia, com a seguinte estrutura: [(data,t_min,t_max,prec)]. A data de cada dia corresponde a um tuplo de inteiros, sendo data = (ano,mes,dia).
Esta aplicação permite, além de criar a tabela pelo utilizador, calcular as temperaturas médias, amplitudes térmicas e valores extremos, comparar valores com limites impostos e desenhar gráficos. Permite também guardar a tabela num ficheiro de texto e recuperá-la. Cada dia é representado por um tuplo ((ano, mês, dia), tmin, tmax, prec), e a tabela por uma lista desses tuplos. 
Para este trabalho utilizei ciclos, condições, funções, listas, tuplos, ficheiros e a biblioteca anteriormente instalada matplotlib.
